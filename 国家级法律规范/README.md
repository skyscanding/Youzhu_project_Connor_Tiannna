# 国家级法律规范数据库

收录与城市更新相关的国家级法律规范原文，支持 Agent 按需检索。

---

## 文件说明

| 文件 | 用途 |
|------|------|
| `国家级法律规范.json` | **主索引**（给其他工具/人工查阅用），17 条记录，含标题、日期、发文号、摘要、原文路径 |
| `registry.json` | **Agent 检索用**，位于**仓库根**，17 条，含章节结构（`chapters[].key_points`），不含正文 |
| `建筑与市政工程抗震通用规范.md` 等 17 个 md | **规范原文**，分章节，Agent 按需读取对应段落 |
| `doc_text2.py` | 遗留 `.doc`（Word 97-2003）解析器 |
| `extract_office.py` | `.docx` / `.xlsx` 解析脚本 |

---

## Agent 使用方法

### 第一步：读 registry 定位
```python
import json
with open("registry.json", encoding="utf-8") as f:
    registry = json.load(f)

# 按 domain 或关键词搜索
for rec in registry["records"]:
    if "抗震" in rec.get("city_update", ""):
        print(rec["title"], rec["gb"], rec["md_file"])
```

### 第二步：按需展开原文
```python
with open(rec["md_file"], encoding="utf-8") as f:
    content = f.read()
# 按章节或关键词切片读对应段落
```

### retrieval intent 规则
- 查询前先读 `registry["_meta"]["domains"] 理解分类体系
- 每条记录含 `domain` + `城市更新关联` 字段，避免在无关规范中搜索
- 章节索引 `chapters[].key_points` 限制单次读取范围，不全文展开
